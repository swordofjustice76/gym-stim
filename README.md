# Gym Stim

Reloadable aluminium gym/EDC stick. **Modular payloads on one tube.** C is always powder. A is a swap puck (sniff / chalk / blank). B is a swap pack (chew dispenser / dry tin / A+B storage liner).

The stick is the product. Powder is the user’s tub.

Repo: [swordofjustice76/gym-stim](https://github.com/swordofjustice76/gym-stim)

## Locked hardware

- **44 × 175 mm**, 6061-T6, type II anodise, clip
- A = bayonet puck: sniff / chalk / blank / Pack AB lid
- B = 40 mm bay: Pack D (18 × 5.5 mm clicker) or Pack T (~35 ml tin) or occupied by Pack AB
- C = three ~32 ml BYO powder cells. Always powder.

## Locked launch (AU)

Empty body + empty puck + empty B pack + empty C. Refills and extra packs as separate SKUs.

Copy: *Same stick. Swap the puck, the mid pack, the powder.*
