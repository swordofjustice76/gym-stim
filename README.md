# Gym Stim

Reloadable aluminium gym/EDC stick. Three chambers: salt cap, chew magazine, BYO pre-workout flask. The stick is the product. Powder is the user’s tub.

## Locked hardware

- 38 mm × 190 mm, 6061-T6, type II anodise, clip
- A = bayonet top puck. Elite = sniff (3–4 ml NH3). Chalk puck (32×12 mm MgCO3 wafer) is a later SKU on the same latch
- B = 8 Fastchew-class discs, ~22 mm cassette, spring clicker
- C = twist-index 3-cell BYO powder carrier

## Locked launch (AU)

Empty body + empty flask + funnel + desiccant + wipe card. Refills later as separate SKUs.
